# ADbrand

## Телеграм Мини-приложение и 2 бота для предоставления магических услуг
### Мини приложение(webs.py 2HTML стр.)
Flask Веб приложение состоит из:
3 маршрутов для разметки страницы
2 обработчиков оплаты
2 кастомных GET\POST апросов для удобного функицонирования
#### Онлайн гадание(rand.html)
Проходит в 3 этапа: 
1. Пользователь задает вопрос, бот присылает страницу с выбором карт
2. Пользователь выбирает карты внутри приложения,
3. Бот с помощую нейронной сети анализирует карты и заданный вопрос и присылает пользователю ответ

#### Печенье с предсказанием(wisher.html)
Каждый день нейронная сеть загадывает предсказания на день, которые пользователи могут посмотреть на второй странице.

### Bot с основным функционалом(bot1)
Внутри бота меню с 8 кнопками, 
1. Кнопка для запуска первой старницы приложения и режима выбора карт
2. Кнопка проверки подписки на новостной канал
3. Кнопка покупки запросов для гадания:
   1. Покупка в рублях через сервис Robokassa
   2. Покупка в TStars(нутрення валюта)
4. Кнопка для запуска второй старницы приложения и режима вскрытия печения с предсказанием
5. Текстовые кнопки

### Bot второстепенным функционалом(bot2)
Внутри бота доступна только оплата в рублях
